# AI Resume Builder & ATS Optimization Platform

An AI-powered resume platform designed to help students and job seekers create ATS-friendly resumes, evaluate their resumes against recruitment requirements, and identify areas for improvement.

## Overview

The project combines resume building, ATS analysis, AI-assisted improvement, and recruitment-oriented insights into a single application.

The goal is to help users move from simply creating a resume to understanding how well it may perform against Applicant Tracking System (ATS) requirements.

## Key Features

- Resume creation and editing
- ATS score analysis
- Resume improvement suggestions
- Hiring prediction
- Interview question generation
- Resume-related data analysis
- Streamlit-based application interface

## Technologies

- Python
- Streamlit
- Machine Learning
- Natural Language Processing
- Data Analysis

## Project Structure

- `app.py` — Main application
- `ats_score.py` — ATS scoring functionality
- `hiring_prediction.py` — Hiring prediction component
- `improvement.py` — Resume improvement functionality
- `interview_questions.py` — Interview question generation
- `dataset/` — Project datasets
- `README.md` — Project documentation

## Purpose

This project was developed to explore how AI and machine learning can be applied to the recruitment and career-development workflow, particularly resume optimization and job preparation.
